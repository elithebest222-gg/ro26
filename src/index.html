    Sign in to Roblox

    webblox sends your password from this browser to Roblox's login service, encrypted end to end (TLS runs here, so the Wisp server only relays scrambled bytes), and never stores it. 2-step verification codes are asked for here. If Roblox wants a CAPTCHA, which only works on roblox.com, use the Cookie option instead.

    Roblox usually refuses a quick sign-in when the code is approved from a different place than where webblox is connecting. Because webblox connects through the Wisp server, this works only when that server is near you (your own, on your network). Otherwise Roblox rejects it; use the Cookie option, which has no such limit.

    Approve this sign-in from a phone or computer where you're already signed in to Roblox. No password, CAPTCHA or verification here.

    Roblox wanted a CAPTCHA for the password sign-in, and its CAPTCHA only works on roblox.com. Signing in with a cookie avoids it.

    The most reliable way in through a Wisp server: paste the session cookie from a browser where you're already signed in. No CAPTCHA, and no location check.

    Your .ROBLOSECURITY cookie is full access to your account. Only paste it into a copy of webblox you trust. It stays in this browser and is only sent to roblox.com, encrypted end to end.
    Where do I find it?

    On roblox.com, signed in: open the developer tools (F12), then Application (Chrome, Edge) or Storage (Firefox) → Cookies → https://www.roblox.com, and copy the whole value of .ROBLOSECURITY.

    Signing out of webblox later only forgets the cookie; the browser you copied it from stays signed in. Roblox may end the session if it suddenly shows up from somewhere far away (the Wisp server's location).

    Sign in on roblox.com itself, inside webblox's browser. Roblox's verification steps can be slow or loop there; if they do, use the Cookie option.
